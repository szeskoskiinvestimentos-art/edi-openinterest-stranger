# Skills

Pasta para armazenar skills criadas pelo sistema.

## Skills Planejadas

1. **project-organizer** - Organização e limpeza do projeto
2. **math-reviewer** - Revisão de cálculos matemáticos
3. **nav-optimizer** - Otimização de navegação entre telas
4. **code-refactorer** - Refatoração de código
5. **evolution-tracker** - Rastreamento de evolução

## Como criar skills

Cada skill deve ter:
- Arquivo `.md` com descrição e regras
- Instruções específicas para tarefas
- Padrões de execução
