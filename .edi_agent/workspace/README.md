# EDI Agent Workspace

Pasta de trabalho persistente do agente de IA.

## Estrutura
- `checkpoints/` - Checkpoints de sessão para retomada
- `skills/` - Habilidades e workflows criados pelo agente
- `evolution/` - Log de evolução e mudanças implementadas
- `learning/` - Aprendizados e descobertas sobre o projeto
- `SESSION_LOG.md` - Log principal de sessões
- `CURRENT_STATE.md` - Estado atual do projeto
- `SKILLS_INDEX.md` - Índice de todas as skills disponíveis
