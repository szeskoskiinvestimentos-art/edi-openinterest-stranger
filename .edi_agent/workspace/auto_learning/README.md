# Auto Learning - EDI Agent

Sistema de aprendizado autônomo do agente.

## Como Funciona
1. Toda sessão registra descobertas em discoveries.md
2. Padrões identificados vão para patterns.md
3. Erros e lições ficam em lessons.md
4. Conhecimento acumulado alimenta o checkpoint

## Estrutura
- discoveries.md - Descobertas específicas desta sessão
- patterns.md - Padrões identificados no código
- lessons.md - Lições aprendidas com erros
- metrics.md - Métricas de qualidade do código
