# Auto-Evolução

Pasta para registro de evoluções e melhorias autônomas.

## Estrutura

- `EVOLUTION_LOG.md` - Log de evoluções
- `IDEAS.md` - Ideias de melhoria
- `IMPLEMENTED.md` - Funcionalidades implementadas

## Modos

- **Auto-Evolução**: Implementar melhorias detectadas
- **Auto-Correção**: Corrigir erros lógicos e de cálculo
- **Auto-Melhoria**: Otimizar código e performance
