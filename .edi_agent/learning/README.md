# Auto-Aprendizado

Pasta para registro de aprendizados do sistema.

## Estrutura

- `LEARNING_LOG.md` - Log principal de aprendizados
- `PATTERNS.md` - Padrões identificados no projeto
- `ERRORS.md` - Erros encontrados e soluções

## Como usar

Sempre que o sistema identificar um padrão, erro ou aprendizado importante, registrar neste diretório para referência futura.
