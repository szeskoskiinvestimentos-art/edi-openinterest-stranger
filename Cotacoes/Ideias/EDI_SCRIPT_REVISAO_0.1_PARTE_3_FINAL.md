## 🔧 TROUBLESHOOTING

### ❌ PROBLEMA: "WDO não encontrado no CSV"

**Soluções:**
1. Verificar se CSV tem "WDO", "WDOc1", ou "Mini Dólar"
2. Se ausente, script usará USD/BRL spot + prêmio estimado
3. Convicção será reduzida para MÉDIA
4. Adicionar WDOc1 ao provedor para próximas vezes

---

### ❌ PROBLEMA: "Curva DI indisponível"

**Soluções:**
1. Verificar se arquivo .xlsx foi anexado corretamente
2. Script tentará usar DDI como fallback
3. Se DDI ausente, buscará contratos DI individuais no CSV
4. Marcar: "⚠️ Curva DI parcial"

---

### 🆕 ❌ PROBLEMA: "FXI e CSI300 ausentes"

**Soluções:**
1. **CRÍTICO para Brasil** - adicionar ao CSV prioritariamente
2. Script usará HSI (Hang Seng) como proxy secundário
3. Se todos ausentes, análise China será qualitativa (notícias)
4. Marcar: "⚠️ China proxies indisponíveis"
5. **Convicção será REDUZIDA em 1 nível**

**Ação recomendada:**
- Adicionar ao CSV: FXI, CSI300, ASHR, MCHI
- Fontes: Yahoo Finance, Investing.com, TradingView

---

### 🆕 ❌ PROBLEMA: "Commodities Brasil incompletas"

**Soluções:**
1. Verificar presença de: Soja (ZS), Minério (TIO/SM58F), Petróleo (CL/BZ), Boi (LE)
2. Script marcará "⚠️ PARCIAL" mas continuará
3. Análise de balança comercial será limitada
4. Adicionar tickers faltantes ao provedor

**Commodities ESSENCIAIS para Brasil:**
- Minério (TIO ou SM58F) - 8% exportações
- Soja (ZS) - 11% exportações  
- Petróleo (CL ou BZ) - 10% exportações (PETR 13% IBOV)
- Boi (LE) - 5% exportações
- Café (KC) - 3% exportações (Brasil = maior exportador)

---

### ❌ PROBLEMA: "Muitos ativos sem atualização"

**Soluções:**
1. Normal antes da abertura do mercado (CSV pode estar desatualizado)
2. Verificar horário do CSV (deve ser pré-mercado)
3. Script marcará "SEM ATUALIZAÇÃO" mas continuará
4. Se >50% sem atualização → considerar buscar CSV mais recente

---
