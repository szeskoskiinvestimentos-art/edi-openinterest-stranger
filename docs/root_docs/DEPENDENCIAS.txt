DEPENDENCIAS / REINSTALAÇÃO (Windows)

Pré-requisitos do sistema
- Git
- Node.js LTS + npm (usado em Cotacoes/)
- PowerShell 7+ (scripts .bat chamam PowerShell)
- Python 3.x (py -3) para os jobs de opções/controle (Auto_B3_System)
- Google Chrome (coleta/scraping do Investing via Chrome)

Dependências do projeto
- Cotacoes/
  - Na primeira instalação (ou após limpar node_modules):
    - npm ci

Variáveis de ambiente
- Cotacoes/.env
  - Use como referência: Cotacoes/.env.example
  - Nunca comitar .env

Execução padrão (pipeline unificado)
- Servico_Unificado_FORCE.bat --no-pause
